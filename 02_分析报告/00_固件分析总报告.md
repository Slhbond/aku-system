## 1. 一句话结论

这是一台 **GoWild（狗尾草）"小小白 / xxb" 陪伴机器人（AKU 版本）**的整机备份，
主控是 **全志 Allwinner sun5i（R8 级，ARM Cortex-A8 + NEON）**，
跑 **Linux 3.4.39 + OpenWrt Barrier Breaker 14.07（Tina Linux V1 r81）**，
板卡代号 **Baymin**，带一颗 **Lattice iCE40UL1K FPGA** 和 **AP6212 WiFi/蓝牙**，
语音走**科大讯飞**、媒体存储走**七牛云**、升级走 **gowildweb.com:6120**。

**关键提醒（关于你点名要的三样）：**

| 你要的 | 结果 |
|---|---|
| **DTS** | 该平台**不使用设备树**（Linux 3.4 全志 BSP 用 `sys_config.fex`/`script.bin`）。全固件 0 命中 FDT 魔数 `d00dfeed`。且 fex 也不在本次备份里 → 见 [`02_kernel_dts/README_dts.md`](../02_kernel_dts/README_dts.md)，已提供**证据化重建**的板级 DTS |
| **U-Boot** | **二进制本体不在备份中**（全志 Boot0/U-Boot 在 NAND 隐藏引导区，按分区备份取不到）。已确认全片扫描无任何 U-Boot 特征串。**但拿到了完整的 U-Boot 环境变量** → 见 [`01_uboot/`](../01_uboot/) |
| **图标** | ✅ **全部提取** — 19 张开机图/电池图标 BMP（已转 PNG + 拼图），并**逆向了 358 帧表情动画格式**，可还原机器人"脸" |

"程序分析"部分见[第 8 节](#8-应用程序分析程序分析)。

## 4. 启动流程

```
Boot0 / eGON (BROM)                       ← NAND 引导区【未备份】
    ↓
U-Boot 2011.09 (sun5i, Baymin Board)      ← NAND 引导区【未备份】
    ↓ bootcmd = run setargs_nand boot_normal
    ↓ bootargs = console=ttyS0,115200 root=/dev/nandd rootwait init=/etc/preinit
    ↓            ion_cma_512m=32m ion_cma_1g=176m ion_carveout_512m=32m
    ↓            ion_carveout_1g=150m coherent_pool=4m loglevel=8 partitions=${partitions}
    ↓ boot_normal = fatload sunxi_flash 2 40100000 uImage ; bootm 40100000
    ↓
Linux 3.4.39 zImage @ 0x40100000
    ↓ 挂 rootfs(squashfs) 到 /，/overlay 到 rootfs_data，/usr 到 extend
    ↓
/etc/preinit → procd → /etc/init.d/rcS S boot
    ↓ (按 /etc/rc.d/S* 顺序)
    S10boot → S20network → S40fstab → S41aw_fstab → S50telnet → S60dbus
    → S62bluez-utils → S80adbd → S96led → S98smartlinkd → S99aw_upgrade_autorun
    ↓
/etc/rc.local  ← 应用在这里启动
        zhc_ipk_install            # 从 UDISK 安装/升级 ipk
        xxb_robot_hw_server &      # 硬件服务（网络/LED/电池/蓝牙/升级）
        xxb_robot_sw_server &      # 软件服务（语音交互主程序）
        zhc_hardware_test &        # 产测程序
```

### 8.4 语音交互链路（逆向自字符串）

```
唤醒 → libcae(CAE 前端，16 kHz) → 录音
     → 讯飞 IAT:  http://bj.voicecloud.cn/msp.do

              result_type=json,vad_enable=1,vad_bos=15000,vad_eos=500,
              sch=1,nlp_version=2.0
     → MSPLogin / QISRSessionBegin / QISRAudioWrite / QISRGetResult
     → 语义结果 → 播报 TTS (QTTSSessionBegin/QTTSTextPut/QTTSAudioGet)
     → 播放本地或云端音频 (gwmplayer / mplayer)
```

播放期间的状态机（字符串）：`Pause because of record` / `Pause because of wakeup` /
`Pause because of user play pause` / `Stop because of play new audio` /
`Resume info:media_type=%d, player_type=%d, time_pos_ms=%d, url=%s`（断点续播）。

### 9.5 表情动画 `.cut` 格式（已逆向 ✅）

这是本次分析的一个额外收获 —— **格式完全破解**：

```

   [2..4]  3 字节 RGB   = 该像素颜色

语义：稀疏像素列表（只存非背景像素），直接写入帧缓冲。

帧缓冲：stride = 256（每行 256 像素），画面 160×128（旋转后为 128×160 面板）
```

## 13. 复现方法

```powershell
# 1) 解压
& 'C:\Program Files\7-Zip\7z.exe' x 'aku原固件.zip' -o00_raw

# 2) FAT 分区（boot-res / boot / private）
& 'C:\Program Files\7-Zip\7z.exe' x 00_raw\boot-res_backup.bin -o03_logos\boot-res

# 3) squashfs（rootfs / extend）
& 'C:\Program Files\7-Zip\7z.exe' x 00_raw\rootfs_backup.bin -o04_rootfs\rootfs
& 'C:\Program Files\7-Zip\7z.exe' x 00_raw\extend_backup.bin  -o04_rootfs\extend

# 4) ipk 两级解包
& 'C:\Program Files\7-Zip\7z.exe' x 04_rootfs\extend\bin\xxb-robot-swapp_0.1.4-6_sun5i.ipk -o06_ipk\swapp
& 'C:\Program Files\7-Zip\7z.exe' x 06_ipk\swapp\xxb-robot-swapp_0.1.4-6_sun5i     -o06_ipk\swapp_inner
& 'C:\Program Files\7-Zip\7z.exe' x 06_ipk\swapp_inner\data.tar.gz                 -o06_ipk\swapp_data
& 'C:\Program Files\7-Zip\7z.exe' x 06_ipk\swapp_data\data.tar                    -o09_app_resources

# 5) 内核/DTB 检查
Format-Hex 02_kernel_dts\boot_fat\uImage -Count 64
```

ELF 分析建议在 WSL/Linux 下做（本机 WSL Ubuntu 已内置 `file`/`readelf`/`strings`/`nm`）：
```bash
file 07_overlay/usr/bin/xxb_robot_sw_server
readelf -d 07_overlay/usr/bin/xxb_robot_sw_server
strings -n 6 07_overlay/usr/lib/libcae.so | grep -i http
```
