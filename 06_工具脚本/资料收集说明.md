> 目标：把"大佬的 Ubuntu"和"你做的 Alpine"两套移植成果整理成可比对、可复现的资料包。
> 本目录下的 `collect-info.sh` 是我写给你们的**一键收集脚本** —— 在移植好的系统上跑一下，
> 该给的资料基本就全了。

---

## 方式一（最推荐）：跑收集脚本

把 `collect-info.sh` 拷到 **Alpine 系统**（和 **Ubuntu 系统**各跑一次），然后：

```sh
sh collect-info.sh
# 或者指定输出位置
sh collect-info.sh /tmp/porting
```

产物是一个 `porting-info-<日期>-<时间>.tar.gz`，把它丢到本目录下就行。

**跑之前建议先补两个工具**，否则设备树只能拿到原始属性、不是完整 dts：

```sh
apk add dtc            # Alpine
apt install device-tree-compiler   # Ubuntu
```

脚本会自动收集：

| 编号 | 内容 | 为什么重要 |
|---|---|---|
| 01 | 基本信息、cmdline、model/compatible、cpuinfo | 确认板级身份 |
| **02** | **设备树（dtc -I fs /proc/device-tree → .dts）** | **最关键的单一文件** |
| 03 | /boot、extlinux.conf、fstab、分区表、MTD | 启动方式与存储布局 |
| 04 | lsmod、/lib/modules 结构、内核配置、内核镜像、DTB | 内核来自哪里、开了什么 |
| 05 | fb/drm 参数 + 显示相关 dmesg | 面板时序 |
| **06** | **WiFi：brcmfmac 参数、管制域、省电、固件列表** | **这次要解决的重点** |
| **07** | **蓝牙：hci/btbcm dmesg、hcd 固件、协议栈** | **这次要解决的重点** |
| 08 | ALSA/asound + 音频相关 dmesg | 验证音频为什么能work |
| 09 | 实际文件：/boot、/lib/modules、/lib/firmware、部分 /etc | 可直接复用 |
| 10 | dmesg 全文 | 兜底，出问题时全靠它 |

## 方式二（最省事）：直接给整盘镜像

如果你（或大佬）的系统跑在 **SD 卡**上，最干脆的做法是**把整张卡 dump 出来**：

**Windows 下**（你有 DiskGenius）：
- 选中整张 SD 卡 → 右键 → **备份分区表/备份磁盘到镜像文件** → 存成 `.img`

**Linux 下**：
```bash
sudo dd if=/dev/sdX of=alpine-sdcard.img bs=4M status=progress conv=fsync
```

> ⚠️ 注意 `if=` 后面是**整张卡**（如 `/dev/sdb`），不是某个分区（`/dev/sdb1`）。
> 写之前务必用 `lsblk` 确认，别把自己的硬盘 dump 了。

整盘镜像信息量最大 —— 我能直接和原厂固件逐项 diff。

## 方式三：手工清单（前两种都做不了时）

### 必须给
1. **设备树**：`*.dts` 源码，或者 `*.dtb`（二进制也行，我能反编译）
2. **内核**：源码树 / 内核镜像 / `.config` / `/lib/modules/<版本>/` （给哪个都行，越多越好）
3. **启动方式**：写在 SD 还是 NAND？用的原厂 U-Boot 还是自己编的？`/boot` 里有什么？
4. **rootfs**：完整镜像，或者 `tar` 打包（**要保留权限和符号链接**：`tar czpf`）
5. **dmesg 全文**

### 特别想要（决定 WiFi/蓝牙能不能修好）
6. `/lib/firmware/brcm/` 全部内容
7. 设备树里 `&mmc1`/`&mmc2` 和 `bluetooth { }` 节点的原文
8. 这几条命令的输出：
```sh
iw reg get
iw dev wlan0 get power_save
dmesg | grep -iE 'brcmfmac|sdio|mmc'
dmesg | grep -iE 'bluetooth|hci|btbcm'
hciconfig -a
```

### 有更好
9. 大佬的**原始教程/笔记/聊天记录**（哪怕零散）
10. 两块板子的实物照片（尤其 **WiFi 模组丝印** 和 **屏幕排线丝印**）
11. 你的 Alpine 和 大佬的 Ubuntu 分别**跑一遍网速测试**的结果（`iperf3` 或测速 App），有对比才好判断差多少
